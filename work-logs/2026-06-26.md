# Home Rack Setup Work Log 2026-06-26

## Aim

Set up remote access to the management network and update server firmware.

## Remote Access via ZeroTier on CCR2216

Replaced the originally planned Raspberry Pi + Tailscale relay approach with ZeroTier running
natively on the MikroTik CCR2216 (RouterOS 7.21.3).

### Setup Steps

1. Installed the ZeroTier extra package for RouterOS (downloaded from mikrotik.com, uploaded via
   Winbox, rebooted to install).

2. Created a new ZeroTier network at my.zerotier.com (private network).

3. Joined the network and authorized the CCR2216 node in ZeroTier Central.

4. Configured ZeroTier interface on RouterOS:

   ```routeros
   /zerotier add name=zt1
   /zerotier interface add instance=zt1 network=<network-id> name=zerotier1
   ```

5. Added firewall rules on RouterOS to allow forwarding between zerotier1 and VLAN interfaces
   (VLAN10/VLAN20).

### Managed Routes Limitation

ZeroTier managed routes (subnet routing via ZeroTier Central) are not available on the free plan.
Workaround: added static routes manually on the client PC.

```sh
ip route add 10.10.10.0/24 via <CCR2216-ZeroTier-IP>
ip route add 10.10.20.0/24 via <CCR2216-ZeroTier-IP>
```

Note this is not saved permanently.

## Server Firmware Update (R440)

### Issues Encountered

1. **Lifecycle Controller online update failed** — LC rejected `downloads.dell.com` as a hostname
   (DNS was not configured).

2. **iDRAC web UI online update failed** — iDRAC was on version 4.10.10.10, which only supports TLS
   1.0/1.1. Dell's servers now require TLS 1.2 minimum, causing LC023 errors.

3. **LC job queue stuck** — After submitting the local firmware upload, the job sat in "New" state
   with error RED023 (Lifecycle Controller in use). Fixed by clearing all jobs in Maintenance → Job
   Queue, then resubmitting.

### Resolution

Downloaded the iDRAC firmware DUP directly from `dell.com/support` (searched by service tag),
uploaded via iDRAC → Maintenance → System Update → Local. Once iDRAC was updated to a current
version (7.x), the online update catalog was accessible and remaining firmware was updated in one
pass.

- All R440 firmware updated to latest versions via LC online catalog.
